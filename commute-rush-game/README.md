# 출근길 08:58:30

> 9시 전까지 지하철 군중을 뚫고 광역버스에 올라타 회사 지문 인식기에 도착하는 2D 탑다운 타임어택 코미디 게임입니다.

## 기술 스택

- Vite
- TypeScript
- Phaser 3
- Vanilla TypeScript
- HTML5 Canvas
- npm

외부 이미지, 백엔드, 데이터베이스, 로그인, 네트워크 기능은 사용하지 않습니다. 화면의 캐릭터와 오브젝트는 Phaser `Graphics`, 기본 도형, 텍스트로 런타임에 생성합니다.

## 설치와 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 Chrome 또는 Edge에서 엽니다.

프로덕션 빌드와 미리보기는 다음 명령을 사용합니다.

```bash
npm run build
npm run preview
```

브라우저 자동 검증은 빌드 후 실행합니다.

```bash
npm run test:e2e
```

## 조작

- `W`, `A`, `S`, `D`: 이동
- `R`: 결과 화면에서 처음부터 재시작
- 탑승, 아이템 사용, 지문 인식은 접촉 시 자동 처리

## 게임 규칙

- 게임은 `08:58:30`에 시작하며 실제 90초 뒤인 `09:00:00`에 지각 처리됩니다.
- 지하철 군중과 닿으면 정신력이 1 감소하고 800ms 동안 재피격되지 않습니다.
- 광역버스 측면의 넓은 판정 영역에 닿으면 자동 탑승하고 회사 앞에서 자동 하차합니다.
- 아이스 아메리카노는 5초 동안 이동 속도를 35% 높입니다.
- 사직서를 주우면 즉시 개그성 게임 오버가 됩니다.
- 고장 난 에스컬레이터는 통과할 수 없으며 아래쪽 계단 통로로 우회해야 합니다.

## 성공 및 실패 조건

- **성공:** `08:59:59`까지 회사 지문 인식기에 접촉
- **지각:** `09:00:00` 도달
- **정신력 고갈:** 정신력 0 도달
- **사직:** 사직서 습득

## 주요 파일 구조

```text
src/
  main.ts                Phaser 게임 생성과 전역 설정
  style.css              캔버스 배치와 페이지 배경
  game/
    GameScene.ts         맵, 이동, 충돌, 상태 머신, HUD, 버스 로직
    config.ts            해상도와 게임 밸런스 수치
    types.ts             게임 상태와 테스트용 타입
tests/
  game.spec.ts           Playwright 필수 시나리오 검증
index.html
vite.config.ts
playwright.config.ts
```

## 밸런스 수정 위치

`src/game/config.ts`의 `GAME_CONFIG`에서 다음 값을 한 번에 조정할 수 있습니다.

- 해상도와 월드 크기
- 플레이어 기본 속도
- 커피 배율과 지속시간
- 시작 시각과 제한시간
- 최대 정신력과 피격 쿨다운
- 군중 수와 이동 속도
- 버스 속도와 재등장 간격

## 알려진 제한사항

- 데스크톱 키보드 조작만 지원합니다.
- 군중과 버스는 게임잼 범위에 맞춘 고정 왕복/직선 경로이며 실제 교통 시뮬레이션이나 경로 탐색은 없습니다.
- 그래픽은 외부 에셋 없이 도형으로 만든 프로토타입 수준입니다.
- 사운드, 세이브, 설정, 모바일 터치, 멀티플레이는 구현하지 않았습니다.
