# 출근길 RUSH 인게임 비주얼 가이드

지하철 스테이지 1차 리워크에서 확정한 코드 기반 시각 규칙입니다. 버스와 회사 스테이지는 이후 같은 규칙을 적용하되, 이번 단계에서는 게임 로직과 공간 구성을 변경하지 않습니다.

## 색상 역할

- 배경: 짙은 청회색과 콘크리트 회색
- 구조물: 저채도 남색과 슬레이트색
- 인터랙션: 노란색과 밝은 하늘색
- 위험: 주황색과 빨간색
- 목적지: 초록색
- HUD: 어두운 남색 패널과 하늘색 강조

색상은 장식이 아니라 역할 전달에 사용합니다. 같은 역할은 다른 스테이지에서도 같은 계열을 유지합니다.

## 월드 레이어

1. 배경과 바닥 패턴
2. 승강장·도로·로비 구조물
3. 비충돌 배경 NPC
4. 플레이어·충돌 NPC·아이템
5. 목적지와 위험 강조
6. 고정 HUD와 결과 UI

배경 NPC는 실제 군중의 밀도만 만들며 충돌과 이동 로직을 추가하지 않습니다.

## 월드 오브젝트

- 표지판: 실제 공간에 부착된 어두운 패널 형태
- 장애물: 충돌 영역과 시각적 외형을 동일한 위치와 크기로 배치
- 아이템: 밝은 외곽 강조와 짧은 효과 라벨 사용
- 목적지: 초록색, 방향 화살표, 장소명과 HUD 목표를 일치
- 위험 NPC: 일반 NPC와 다른 실루엣·색상·월드 배지 사용

## NPC

- 직장인: 저채도 정장과 가방 또는 스마트폰
- 일반 승객: 색상과 소품으로만 변형
- 방해 NPC: 빨간 계열 외곽선과 경고 배지

캐릭터 해상도와 충돌 크기는 기존 값을 유지하며, 배경 군중은 축소·반투명 처리해 실제 장애물 NPC와 구분합니다.

## 성능 원칙

- Phaser Graphics로 생성한 작은 런타임 텍스처와 단순 도형 사용
- 거대한 단일 배경 이미지와 신규 렌더링 프레임워크 사용 금지
- 배경 NPC에 물리·AI·경로 탐색을 추가하지 않음
- 재시작 시 Scene 수명주기에 따라 모든 월드 오브젝트를 일괄 정리
